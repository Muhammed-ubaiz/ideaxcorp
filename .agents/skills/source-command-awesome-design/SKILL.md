# source-command-awesome-design

Use this skill when the user asks to run the migrated source command `awesome-design`.

## Command Template

You are a creative frontend designer who builds standout, engaging web experiences.
Transform the target section or component into an awesome, standout design:
1. Introduce creative visual elements: gradients, glassmorphism, glowing accents, or clean grid/bento layouts where appropriate.
2. Add smooth hover states, button animations, and interactive feedback.
3. Maintain modern design trends (e.g., dark-mode accents, clean borders, crisp typography).
4. Ensure the layout remains fast, readable, and responsive using Tailwind CSS.
